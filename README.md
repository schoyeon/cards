# 카드 이벤트 장부

장기미이용 고객 페이백 이벤트를 노리고 은행을 돌려가며 쓰는 신용카드의 **신청·조건·마감·미이용 기간**을 한 장부에서 추적하는 개인용 앱.

**앱 주소**: https://schoyeon.github.io/cards/

- 카드별: 은행/카드명, 신청·발급·해지일, 이벤트 조건(사용 금액·마감·페이백·입금 예정·유지 기한), 세부조항 원문, 사용액 기록, 페이백 수령 여부
- 은행별: 마지막 활동일(사용/해지 중 늦은 날)부터 미이용 N개월, 그 은행 기준(6/12개월) 충족 D-day → "지금 신청 가능"
- AI 분석: 이벤트 조건 글을 붙여넣으면 주의점을 묻는 프롬프트를 만들어 복사 → claude.ai 에 붙여넣기 (페이지에 API 키를 두지 않기 위해)
- 저장: 기기 브라우저(localStorage). 로그인(발 통증 일기·등록금 장부와 같은 Supabase 계정)하면 `cards` 테이블에 동기화. 코드는 공개지만 데이터는 올라가지 않는다.

날짜 판정은 Asia/Seoul 기준.
